# 一箭又一箭

## 项目简介
基于 Python 和 Pygame 开发的休闲解谜小游戏。玩家需要点击箭头使其飞出棋盘，前方有阻挡则失误+1。

## 开发环境
- Python 3.10
- Pygame 2.5.2

## 安装和运行方法
1. 确保已安装 Python。
2. 在终端执行 `pip install pygame` 安装依赖。
3. 运行游戏：`python arrow.py`

## 游戏操作说明
- 鼠标左键点击箭头：若前方无阻挡，箭头飞出并消失；若有阻挡，失误+1，箭头抖动。
- 右上角“重新开始”按钮：重置当前关卡。
- 失误达到 3 次或通关全部关卡后，点击屏幕可重新开始。
